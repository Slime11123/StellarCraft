# 切地图清空 MC 内容（2026-10-14）

用户将上轮“新地图重同步旧方块/实体”改为：切换剑星地图后清空旧地图登记的 MC 生物与方块，返回旧地图不恢复。已实现并备份安装；仅离线验证，未启动游戏、发送输入或写 QA 指令。

- 在 SbState 原保留字段 0x3C 发布稳定地图名称哈希 mapId；levelId 仍是带 epoch 的运行期对象身份。共享内存大小、偏移、v6 版本和 C 导出 ABI 保持不变，Lua 私有发布函数增加可选第 14 参数。失效世界 mapId=0，旧调用省略参数也写 0，不触发清空。F4、同地图重绑/复活和同地图重载不因运行期 epoch 改变而清空。
- `PlacedBlocks` 账本记录 NativeMapId/NativeEpoch。首次观察只关联当前地图，实际地图改变时取出登记位置，清除方块/偏移并立即保存空账本。返回旧地图或重启 MC 后，也不会从账本恢复已清除的方块。
- `BlockBridge` 先停掉原有同步批次/放置意图，等待集成服务端清理完成再同步新空场景。服务端只处理登记位置且核对原方块类型，以无掉落、无邻居更新的方式移除；不扫描/删除后台 MC 地形，不访问剑星原生场景。
- `NativeEntities` 在服务端丢弃旧代次登记实体，包括登记生物、船、TNT 和投射物。实体代次标签与持久账本代次配对；未加载区块中再次出现的旧登记实体，在参与原生模拟/渲染前丢弃。未登记的隐藏 MC 生物、玩家、Eve 和原生 NPC 不进入此清理表。渲染快照同时带代次，清图时不会把上一个服务端 Tick 的生物再导出。
- MC 与 DLL/main.lua 须配套部署。其余生命周期防护和伤害/身份/ABI 门禁保留；原点磁盘文件仅保存坐标标量，不删除，不会使清空的方块重新出现。
