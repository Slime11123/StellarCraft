# 剑星原生 MC 世界扩展

## 顺序与验收

1. 完成台阶、连续移动、蹲姿、单次放置、F4 往返放置、HUD 黑边、后台世界隔离和新放方块持久化的检查。台阶只允许跨越可行走面，保留墙体和头顶碰撞。
2. 生物生成蛋和船：记录原生实体身份，仅复制玩家在剑星投放的实体；原版模型和贴图转成剑星世界几何，接受剑星灯光、深度和阴影。后台实体不复制。物理碰撞以剑星为准。
3. TNT：点火后同步引信和实体，爆炸粒子在剑星世界显示；删除范围内的已登记 MC 方块。伤害白名单为原生 MC 实体和已确认的剑星敌人，排除 Eve、NPC、剑星场景与后台 MC 生物。
4. MC 光源：按方块实际发光状态创建动态点光，熄灭/破坏/爆炸立即撤灯。限制活跃灯数和距离，检查性能。
5. 末影珍珠：原版投掷初速度，剑星碰撞决定命中；传送前验证目标落脚和胶囊空间，并用已有位置确认通道同步两边。

## 首领模式 F4 崩溃排查计划（本次只规划）

- 收集同一次切换的 Minecraft crash-report、hs_err、UE4SS 日志和切换前后的控制/世界/角色状态，区分 Java 异常、原生崩溃与进程退出。
- 在普通地图与首领模式对照记录 actor proxy 创建、属性注册、渲染器、世界/角色更换，以及原生实体帧所用的世界标识。
- 确认错误发生在哪一步，再增加对应的有效性检查或生命周期重建；避免对失效的 pawn/world/渲染器继续调用。
- 以进入首领模式、F4 首次切换、往返切换、首领死亡/重试、退出首领模式分别回归；保留普通存档放置与飞行回归。

本计划不代表上述扩展已实现或已通过实机验收。每项的安装版本与实际验证证据另行记录。
