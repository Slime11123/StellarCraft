# 盾伤按实时护盾上限换算

2026-10-15：用户在“一击破盾”的只读诊断后明确要求“执行”，本次替代原方案的同一 HP 系数规则。

## 实现

生产结算只改变 `native_combat.h::actor_at()` 的盾路由换算基数：

- 盾伤：`min(currentShield, liveMaxShield * mcDamage / tierBudget)`。
- HP：沿用原 `converted_damage()`，不改变伤害预算、上限或死亡路径。
- 有盾的本击仅扣盾；本击破盾不溢出 HP，下一击重新读当前盾后决定路由。护盾恢复/上限变化仍逐击读取。
- 免伤、身份/来源/版本/线程、时效/去重、调用后身份/池重读和受击 Show 门禁均保留；无盾槽照常走 HP。没有新配置或手写盾值，原生整数截断保持。
- `tools/hp_conversion.py` 的说明同步更新；Lua 回归桩的盾换算基数随实现更新。Lua 生产代码、JAR、addon及公开 v6 协议没有变动。
