# StellarCraft MC 侧 mod 本地编译说明

## 这是什么

StellarCraft（Minecraft ↔ 剑星互通）的 MC 侧 mod，目标平台 **Forge 1.20.1-47.4.10**。
包含皮肤/披风同步、实体代理、碰撞导出、爆炸伤害桥接等完整功能。

## 为什么需要你自己编译

这个项目最初在 WorkBuddy 的**沙箱环境**里尝试编译，但遇到了环境级的硬限制：

- 沙箱注入了强制代理 `127.0.0.1:54498`
- ForgeGradle 6 插件内部**硬编码**访问 `maven.minecraftforge.net` 下载 MC 版本清单（`forge-1.20.1-47.4.10.json`）
- 该源在沙箱网络下完全不可达（实测 10 秒超时，000）

**你在自己电脑上编译，没有这些问题**，网络直连正常，一条命令即可完成。

## 环境要求

| 项目 | 要求 | 说明 |
|------|------|------|
| Java | JDK 17 | 必须，1.20.1 用 Java 17 编译 |
| Gradle | 无需单独安装 | 项目自带 gradlew wrapper，自动下载 |
| 网络 | 能访问 maven.minecraftforge.net | 国内需可访问（或用代理） |
| 磁盘 | ~2GB 空闲 | 首次反编译 MC 需要 |

## 编译步骤

### 1. 解压源码包

把 `stellarcraft-mcmod-forge-源码交付包.zip` 解压到任意目录，得到 `mc-mod/` 文件夹。

### 2. 确认 Java 17

```
java -version
```
应显示 `17.x`。如果不是，先安装 JDK 17 并设置 `JAVA_HOME`。

### 3. 一键编译

Windows 双击运行，或在 `mc-mod/` 目录打开命令行执行：

```
gradlew.bat build
```

首次编译会：
1. 下载 ForgeGradle 6 插件
2. 下载 Forge 1.20.1-47.4.10 依赖 + 反编译 Minecraft（约 10-15 分钟）
3. 编译 mod 代码

### 4. 拿到 mod jar

编译成功后，产物在：

```
mc-mod/build/libs/stellarcraft-1.0.0.jar
```

## 安装到游戏

1. 打开你的 PCL 启动器，进入 `1.20.1-Forge_47.4.10` 实例
2. 打开 `.minecraft/mods/` 文件夹
3. 把 `stellarcraft-1.0.0.jar` 丢进去
4. 启动游戏，mod 会自动加载

## 国内网络加速（可选）

如果下载 ForgeGradle 依赖慢，可以在 `gradle.properties` 里临时加一行走镜像（BMCLAPI）：

```
systemProp.https.proxyHost=
```

或参考 `settings.gradle`，把 `maven.minecraftforge.net` 换成 `https://bmclapi2.bangbang93.com/maven/`（注意：ForgeGradle 插件内部仍会访问官方源下载版本清单，镜像不覆盖这个文件，所以最终还是需要能直连官方源）。

## 代码结构

```
mc-mod/src/main/java/dev/stellarcraft/
├── StellarCraftMod.java          # @Mod 主入口 + Forge 事件总线
├── NativeBridge.java             # 共享内存 native 桥接
├── client/
│   ├── ClientBridge.java         # 客户端 tick 主循环
│   ├── AppearanceBridge.java     # 皮肤/披风同步（本次新增）
│   ├── ControlStateMachine.java  # F4 切换 Eve/Steve
│   └── OverlayCompositor.java    # HUD 叠加
├── link/
│   ├── Proto.java                # 协议常量
│   └── SharedMemory.java         # 共享内存读写
└── world/
    ├── ActorProxy.java           # 实体代理
    ├── EntityRegistry.java       # DeferredRegister 实体注册
    ├── EntityCollisionMixin.java # 碰撞
    ├── ExplosionMixin.java       # TNT 爆炸
    └── DamageBridge.java         # 伤害桥接
```

## 常见问题

**Q: 编译报 `Cannot resolve net.minecraftforge:forge:1.20.1-47.4.10`**
A: 网络连不上官方 maven。检查能否打开 `https://maven.minecraftforge.net`，必要时挂代理。

**Q: 报 `Unsupported class file major version`**
A: Java 版本不对，必须用 JDK 17（不是 21，不是 8）。

**Q: 首次编译很久**
A: 正常，首次要反编译整个 Minecraft 1.20.1，之后增量编译只要几十秒。
