## The idea

SkyCraft proved the pattern with Skyrim (github.com/chasmlol/SkyCraft). StellarCraft applies the same architecture to Stellar Blade, which turns out to be *more* tractable than Skyrim in one key way: Stellar Blade PC is **Unreal Engine 4.26**, and the community has already ported **UE4SS** to it — the UE4SS C++ Modding API is Stellar Blade's equivalent of Skyrim's SKSE.

| Concern | Skyrim | Stellar Blade |
|---|---|---|
| Injection | SKSE (official) | UE4SS (community fork) |
| Symbols/offsets | Address Library | UE4SS UHT/C++ header dumper |
| Runtime object access | CommonLibSSE | UE4SS C++ API (UE object system) |
| Injection method | SKSE loader | dwmapi.dll proxy |

## How it works

```
 StellarBlade.exe (UE4.26 + UE4SS mod)  ◄── shared memory ──►  javaw.exe (Minecraft 26.3 + Fabric mod)
  collision export / NPC mirror / input / hit   <─ Local\StellarCraft_v1 ─>   collision field / actor proxies / input / render
```

The full architecture, coordinate mapping, authority split, combat bridge, and rendering pipeline are in **[docs/DESIGN.md](docs/DESIGN.md)**.

## What's implemented

This repository is a **skeleton**, not a shipping mod. It contains:

- **Protocol** (`protocol/stellarcraft_protocol.h`) — single source of truth for the shared-memory byte layout.
- **MC-side Java** (`mc-mod/`) — the Fabric mod: `CollisionField`, `EntityCollisionMixin` (collision injection), `ActorProxy`, `DamageBridge`, `ClientBridge`, `OverlayCompositor`, `SharedMemory` + `RingBuffer` + JNI bridge.
- **SB-side C++** (`sb-mod/`) — the UE4SS mod structure: `collision_exporter`, `actor_mirror`, `input_bridge`, `overlay`, entrypoint.
- **Design doc** (`docs/DESIGN.md`).

### What's NOT yet done (needs real work)

- Unreal SDK headers (generated by UE4SS's UHT dumper for Stellar Blade) and concrete offsets.
- Actual collision export (Unreal trace/collision-primitive voxelization).
- Rendering transport (GPU interop or the CPU readback loop).
- A full Fabric dev environment (Gradle/Loom) to compile and test the MC side.

## Building

**Minecraft side** (needs JDK 25 + a Fabric Loom environment):

```bash
cd mc-mod
./gradlew build
```

**Stellar Blade side** (needs VS 2022 + xmake + UE4SS build of Stellar Blade's UE4.26 headers):

```bash
cd sb-mod
xmake f -m "Game__Shipping__Win64"
xmake build
```
