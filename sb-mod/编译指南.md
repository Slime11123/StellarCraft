# 剑星侧 mod 编译指南（StellarCraft）

本文档说明如何编译剑星侧（UE4SS C++ mod）的 DLL。

## 前置条件（已检测通过）

| 工具 | 状态 | 说明 |
|---|---|---|
| Visual Studio 2022 Community | ✅ 已安装 | 含 C++ 桌面开发工作负载 |
| MSVC 编译器 cl.exe | ✅ 已安装 | 版本 14.38.33130，位于 `C:\Program Files\Microsoft Visual Studio\2022\Community\VC\Tools\MSVC\14.38.33130\` |
| xmake | ⬜ 需安装 | UE4SS 官方推荐的构建工具 |

## 一、安装 xmake

1. 下载 xmake bundle（自带工具链，最省事）：
   - 官网：https://xmake.io/#/download
   - 或 GitHub release：`xmake-bundle-v3.1.1.win64.exe`
   - 国内加速：`https://gh-proxy.com/https://github.com/xmake-io/xmake/releases/download/v3.1.1/xmake-bundle-v3.1.1.win64.exe`
2. 运行安装器，勾选 **"添加到 PATH"**。
3. 新开一个终端，验证：`xmake --version`

## 二、编译剑星侧 mod

```bash
cd stellarcraft/sb-mod
xmake            # 默认 release 模式编译
```

产物：`build/windows/x64/release/stellarcraft_sb.dll`

### 编译选项

| 命令 | 说明 |
|---|---|
| `xmake` | 默认编译（release） |
| `xmake f --sdk=y && xmake` | 启用 SDK 头文件编译（逆向完成后用） |
| `xmake f -m debug && xmake` | 调试模式（带符号） |

## 三、当前编译状态

**当前骨架代码是「自包含」的**：只依赖 `windows.h` 和协议头 `protocol/stellarcraft_protocol.h`，SDK 头文件仍为注释状态。

这意味着**现在就能编译通过**，用于验证：
- 协议层字节布局（`static_assert` 全部校验）
- 共享内存映射创建/读写
- 各模块（collision_exporter / actor_mirror / input_bridge / overlay / control_switch / damage_applier）的框架代码无语法错误

**SDK 逆向完成后**：用 `xmake f --sdk=y` 启用 SDK 头文件，再填 `stellar_blade_mod.cpp` 里注释掉的真实实现。

## 四、部署到剑星

编译出的 `stellarcraft_sb.dll` 需要放到 UE4SS 的 mod 加载目录，并通过 UE4SS 的 C++ Modding API 加载。

> 具体加载机制（dwmapi.dll 代理 + UE4SS mod 注册）在 `docs/DESIGN.md` 的 Phase 0 章节有说明。骨架的 `start_mod()` / `uninstall_mod()` 就是 UE4SS C++ mod 的标准入口。

## 五、常见问题

| 问题 | 解决 |
|---|---|
| `xmake: command not found` | 安装时未勾选 PATH，重装或手动加 PATH |
| `cl.exe 未找到` | xmake 会自动检测 VS2022，若失败用 `xmake f --vs=2022` |
| 中文路径编译报错 | 项目路径含中文可能有问题，建议移到纯英文路径 |
